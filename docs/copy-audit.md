# Roll Call player-facing copy audit

Audit date: 2026-09-28

Scope: `index.html` and all non-test code under `src/`, including rendered React copy, accessibility labels, tooltips, modal/popover copy, responsive-only variants, shared definitions, validation errors, resolution messages, and the player-openable Run Info/history/debug UI. Developer comments, test descriptions, internal identifiers, console-only text, and telemetry fields that are never rendered are excluded.

Conventions:

- Text in braces is a readable runtime placeholder, not a rewrite: for example, `{score}`, `{hand}`, or `{n}`.
- Alternatives separated by `<br>` are mutually exclusive or related strings emitted by the same UI item.
- `A11Y ONLY` identifies text exposed to assistive technology or browser title text but not normally drawn on screen.
- Run-history messages are included because the player can open **Run Info → History**, and the current event message also appears during playback.
- No Rive dependency or Rive-authored player-visible text exists in the audited source.

1. **Gold capitalization:** `Gold` and `gold` both appear in descriptions, prices, buttons, rewards, errors, and history messages.
2. **Shop naming/capitalization:** `Shop`, `shop`, `normal Shop`, `normal-Shop`, and `normal-shop` all appear.

4. **Scoring goal:** `goal`, `target`, `round target`, `points`, `pts`, `score`, and `{score} / {target}` overlap. Target Practice also uses “target” to mean a hand.
5. **Multiplication notation:** `×`, `x`, and `*` all appear. `MULT`, `Mult`, `multiplier`, `XMULT`, `XMult`, `factor`, `stored factor`, and `meter` overlap.
6. **Hand availability:** `used`, `use up`, `consumed`, `locked`, `cooling down`, `cooldown`, `recharge`, and `normal hand availability unchanged` describe related states.
7. **Levels:** `Lv.`, `Lv.{n}`, `LV.`, `level`, and `Hand levels` are mixed.
8. **Dice/faces:** `die`, `player die`, `physical die`, `D{n}`, `face`, `physical face`, `printed face`, `side`, `exposed face`, and `showing` overlap.
